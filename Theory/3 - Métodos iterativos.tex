\section{Métodos iterativos para resolver sistemas lineales}
\subsection{Motivación}

Si tenemos un sistema lineal $Ax = b$ con $A \in \mathbb{R}^{n \times n}$, $b \in \mathbb{R}^n$ y $x \in \mathbb{R}^n$, suficientemente grande, el método de eliminación gaussiana puede resultar ineficiente, al tener coste $O(n^3)$ en términos de tiempoº. En estos casos, los métodos iterativos pueden ser una alternativa más adecuada.\\

La idea de este tipo de metodos va a ser escoger una matriz $M$:

\[
    A = M - N
\]

Que cumpla que $M$ es fácil de invertir, y que sea similar a $A$ (prefiriblemente, $M=A$). Entonces, el sistema $Ax = b$ se puede reescribir como:

\[
    Mx = Nx + b \implies
    x = M^{-1}Nx + M^{-1}b \xrightarrow{\text{Notación}}
    x_{k} = Bx_{k-1} + C
\]

Por lo que podemos utilizar esta ultima expresión para generar una sucesión de aproximaciones a la solución del sistema, partiendo de una aproximación inicial $x_0$, la cual convergera a la solución del sistema:

\[
    \lim_{k \to \infty} x_k = \xi
\]

\subsection{Convergencia de métodos iterativos}

\begin{definición}[Convergencia de métodos iterativos]
    El metodo iterativo $(*)$ se dice que converge si la sucesión de aproximaciones $x_k$ converge a la solución exacta $\xi$ del sistema lineal $Ax = b$, es decir:
    \[
        \lim_{k \to \infty} x_k = \xi \quad \forall x_0 \in \mathbb{R}^n
    \]
\end{definición}

Notese que $B$ no se calcula de forma explicita, sino que se utiliza:

\[
    \begin{cases}
        w = Nx_{k-1} + b \\
        Mx_k = w
    \end{cases}
\]

Notese el caso particular de $M = A$, que se conoce como método de iteración de Richardson, y que es el método iterativo mas simple, ya que la primera iteración nos devuelve $x_1 = \xi$, es decir, la solución exacta del sistema. Sin embargo, este método no es eficiente, ya que requiere resolver el sistema $Ax = b$ en cada iteración, lo cual es tan costoso como resolver el sistema original.\\

Veamos ahora algunos criterios de convergencia.

\begin{proposición}[Error en métodos iterativos]
    Teniendo un metodo iterativo, podemos definir el error:
    \[
        e_k = 
        x_k - \xi = 
        Bx_{k-1} + C - \xi \underbrace{=}_{*}
        Bx_{k-1} + C - B\xi - C =
        B(x_{k-1} - \xi) =
        Be_{k-1} =
        B^k e_0
    \]
    Donde el paso $(*)$ se ha realizado utilizando:
    \[
        A \xi = b \implies
        (M - N)\xi = b \implies
        M\xi = N\xi + b \implies
        \xi = M^{-1}N\xi + M^{-1}b = B\xi + C
    \]
    Por lo que el error converge a 0 si y solo si:
    \[
        \lim_{k \to \infty} \| e_k \| = 0 \iff 
        \lim_{k \to \infty} \| B^k e_0 \| = 0 \iff
        \| B \| < 1 \iff
        \rho(B) < 1
    \]
\end{proposición}

\begin{proposición}[Criterios de parada]
    Para determinar cuándo detener el proceso iterativo, se pueden usar los siguientes criterios:
    \begin{itemize}
        \item Criterio de iteraciones: Detener después de un número fijo de iteraciones $K_\text{max}$.
        \item Criterio de error: Detener cuando el error estimado $\| e_k \|$ sea menor que una tolerancia predefinida $\varepsilon = \text{TOL}$. Esto no se puede aplicar directamente, ya que no conocemos el error real, pero se pueden usar varias posibilidades para estimar el error, el cual se define como:
        \[
            E_k = \frac{ \| e_k \| }{ \| \xi \| } = \frac{ \| x_k - \xi \| }{ \| \xi \| }
        \]
        Por ello veamos distintos métodos para estimar el error real:
        \begin{itemize}
            \item \textbf{Error relativo:} Se puede usar el error relativo entre iteraciones consecutivas como una estimación del error real, es decir:
            \[
                \| e_k \| \approx 
                \widetilde{E_k} = 
                \frac{\| x_k - x_{k-1} \|}{ \| x_k \| }
            \]
            \item \textbf{Error de residuos:} Se puede usar el residuo del sistema lineal como una estimación del error real, es decir, si definimos el residuo:
            \[
                r_k =
                b_k - b =
                Ax_k - b
                Ax_k - A\xi =
                A(x_k - \xi) =
                Ae_k
            \]
            Y por tanto podemos estimar el error real como:
            \[
                \| e_k \| \approx
                \overline{E_k} =
                \frac{ \| b_k - b \| }{ \| b \| } =
                \frac{ \| r_k \| }{ \| b \| } =
                \frac{ \| A(x_k - \xi) \| }{ \| A\xi \| } \approx
                \frac{ \| x_k - \xi \| }{ \| \xi \| } =
                E_k
            \]
            \end{itemize}
    \end{itemize}
\end{proposición}

\begin{teorema}[Metodo de Jacobi]
    Sea la descomposición de $A=M-N$, y sea tambien su dscomposición en bloques:
    \[
        A = D - E - F
    \]
    \begin{center}
    \[
        \left(
        \begin{tikzpicture}[baseline=(current bounding box.center)]
            % Triangulo superior
            \draw[thick, green] (-1.5, 2.5) -- (2.5,2.5) -- (2.5,-1.5) -- (-1.5,2.5);
            % Triangulo inferior
            \draw[thick, blue] (-2.5,-2.5) -- (-2.5,1.5) -- (1.5,-2.5) -- (-2.5,-2.5);
            % Diagonal
            \draw[thick, red] (-2, 2.5) -- (2.5, -2) -- (2, -2.5) -- (-2.5, 2) -- (-2, 2.5);
            % Etiquetas
            \node at (0, 0) {D};
            \node at (-1.25, -1.25) {E};
            \node at (1.25, 1.25) {F};
        \end{tikzpicture}
        \right)
    \]
    \end{center}
    Es decir, que:
    \[
        D = \text{diag}(a_{11}, a_{22}, \dots, a_{nn})
    \]
    \[
        E = (e_{ij})_{i,j=1}^n, \quad \begin{cases}
            e_{ij} = a_{ij} & \text{si } i > j \\
            e_{ij} = 0 & \text{si } i \leq j
        \end{cases}
    \]
    \[
        F = (f_{ij})_{i,j=1}^n, \quad \begin{cases}
            f_{ij} = a_{ij} & \text{si } i < j \\
            f_{ij} = 0 & \text{si } i \geq j
        \end{cases}
    \]
    El método de Jacobi se define como el método iterativo generado por la matriz $M = D$, es decir:
    \[
    \begin{cases}
        x_0 \in \mathbb{K}^n \\
        Dx_k = (E + F)x_{k-1} + b \quad k \in \mathbb{N}
    \end{cases}
    \]
    Y la matriz del método de Jacobi es:
    \[
        J = \underbrace{D^{-1}}_{M^{-1}} \underbrace{(E+F)}_{N} = D^{-1}(D - A) = I - D^{-1}A
    \]
    Para que el método este bien planteado, es necesario que $D$ sea invertible, es decir, que $a_{ii} \neq 0$ para todo $i = 1, \dots, n$, si alguno es cero pero $\det(D) \neq 0$, entonces permutamos.\\
    Para iterar definimos el operador de iteración del método de Jacobi:
    \[
        x_i^{(k)} =
        \left(b_i - \sum_{j \neq i} a_{ij} x_j^{(k-1)}\right) / a_{ii}  
        \quad i \in \{1, \dots, n\}
    \]
    Que tiene complejidad $O(n^2)$, ya que cada iteración requiere calcular $n$ sumas de $n-1$ elementos.\\
\end{teorema}

Veamos ahora varios criterios de convergencia del método de Jacobi.

\begin{proposición}[Convergencia del método de Jacobi]
    El método de Jacobi converge si:
    \[
        \rho(J) < 1
    \]
\end{proposición}

\ejemplo{
    Tengamos el sistema:
    \[
    \begin{pmatrix}
        -1 & 3 \\
        -2 & 1
    \end{pmatrix}
    x =
    \begin{pmatrix}
        1 \\
        2
    \end{pmatrix}
    \]
    Podemos tomar:
    \[
        M = D =
        \begin{pmatrix}
            -1 & 0 \\
            0 & 1
        \end{pmatrix}
        \,\text{y} \, \quad
        N = E + F =
        \begin{pmatrix}
            0 & -3 \\
            2 & 0
        \end{pmatrix}
    \]
    Si definimos ahora:
    \[
        J = D^{-1}(E + F) =
        \begin{pmatrix}
            0 & 3 \\
            2 & 0
        \end{pmatrix} \implies
        \det(J - \lambda I) =
        \begin{vmatrix}
            -\lambda & 3 \\
            2 & -\lambda
        \end{vmatrix} =
        \lambda^2 - 6 = 0 \implies
        \lambda = \pm \sqrt{6} > 1
    \]
    Por lo que el método de Jacobi no converge para este sistema lineal.
}

\begin{definición}[Matriz d.e.d.]
    Una matriz $A \in \mathbb{K}^{n \times n}$ es diagonal estrictamente dominante (d.e.d.) si:
    \[
        |a_{ii}| > \sum_{j \neq i} |a_{ij}| \quad \forall i = 1, \dots, n
    \]
\end{definición}

\begin{teorema}[Convergencia del método de Jacobi para matrices d.e.d.]
    Sea $A$ una matriz d.e.d., entonces el método de Jacobi converge.
\end{teorema}

\begin{lema}
    Sea $A$ una matriz d.e.d., entonces:
    \[
        \exists A^{-1}
    \]
\end{lema}

\begin{proof}
    Supongamos que $A$ no es invertible, entonces el sistema $Ax = 0$ tiene infinitas soluciones. Sea $x \neq 0$ solucion del sistema, por lo que $\exists i \in \{1, \dots, n\}$ tal que $|x_i| = \max_{j} |x_j| > 0$. Entonces:
    \[
        a_{ii} x_i + \sum_{j \neq i} a_{ij} x_j = 0 \implies
        - a_{ii} x_i = \sum_{j \neq i} a_{ij} x_j \implies
        |a_{ii}| |x_i| \leq \sum_{j \neq i} |a_{ij}| |x_j| \implies
    \]
    \[
        |a_{ii}| \leq \sum_{j \neq i} |a_{ij}| \frac{ \| x_j \| }{ \| x_i \| } \implies
        |a_{ii}| \leq \sum_{j \neq i} |a_{ij}| \implies
        \text{Contradicción!!}
    \]
    Por lo que necesariamente $A$ es invertible.
\end{proof}
